# EcoCycle AI – Integrated AI Waste Management & Circular Economy Platform

**Live Deployed Application:** [https://ecocycle-seven-tau.vercel.app](https://ecocycle-seven-tau.vercel.app)

## Overview
EcoCycle AI is an end-to-end smart campus and urban waste management platform designed to accelerate a zero-landfill circular economy through AI-assisted waste segregation, IoT smart-bin route optimization, and gamified recycling incentives.

## Key Features
- **AI Waste Segregation Scanner:** Classifies waste items (Plastic, E-Waste, Organic, Glass, Metal) with confidence scoring, proper disposal guidance, and instant Eco-Points rewards.
- **Smart Bin & Route Optimizer:** Monitors real-time smart-bin fill levels across campus zones and dynamically calculates low-emission collection routes to prevent overflow.
- **Circular Economy Marketplace:** Allows users to trade reusable items, list recyclables, and redeem earned Eco-Points for campus coupons and rewards.
- **Impact Analytics Command Center:** Tracks landfill diversion rates, total waste recycled, active contributors, and $\text{CO}_2$ emissions saved in real time.

## Tech Stack
- **Framework:** Next.js (App Router) & React
- **Styling & UI:** Tailwind CSS, Shadcn UI, Lucide Icons
